# Alpha Prime

The General. Autonomous. Self-healing. One bot, one command, one Forgemaster.

## What Alpha Prime Is

Alpha Prime is a unified AI agent that integrates three powerful capabilities into a single, self-healing entity:

- **Hermes** (Memory & Learning): Self-learning memory, pattern detection, skill creation
- **AIlice** (Agent Factory): Creates specialized agents on demand
- **RuFlo** (Orchestration): Autonomous mission scanning, health monitoring
